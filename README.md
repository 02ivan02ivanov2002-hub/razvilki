# Развилки

Статический сайт с интерактивными тестами-симуляторами выбора.
Живёт на https://razvilki.vercel.app/ — без сборки и бэкенда.

## Структура

- `index.html` — приложение (список тестов, прохождение, итог).
- `app.js` — логика: роутинг по hash, ресурсы, концовки, тема, звук, шаринг.
- `scenarios.js` — контент: сценарии, шаги, варианты, концовки. **Правится здесь.**
- `style.css` — оформление, светлая и тёмная темы.
- `tests/`, `about/` — статические страницы для поиска (генерируются).
- `tools/build-pages.mjs` — генератор этих страниц и `sitemap.xml`.
- `og-image.png`, `robots.txt`, `vercel.json` — обвязка.

## Как добавить сценарий

1. Добавить объект в `scenarios.js` (шаги, эффекты, концовки).
2. Добавить вводные абзацы в `INTRO` в `tools/build-pages.mjs` — необязательно,
   без них на странице будет только `tagline`.
3. Пересобрать страницы:

   ```bash
   node tools/build-pages.mjs
   ```

4. Увеличить номер версии ассетов в `index.html` и в `CSS_VERSION` внутри
   `tools/build-pages.mjs`, чтобы браузеры не закешировали старые файлы.
5. Закоммитить/задеплоить. `tools/` и `README.md` не попадают на прод
   (см. `.vercelignore`).

## Проверки

```bash
node --check app.js
node --check scenarios.js
node --check tools/build-pages.mjs
```
